# 💰 User Management System – Deposits & Withdrawals

A modern web-based user management system designed for handling user accounts, deposits, withdrawals, and balance tracking through an intuitive interface.

## 🌐 Live Demo

👉 https://mohammad-arhami.github.io/User-Management-System-Deposits-and-Withdrawals/

---

## 📖 Overview

The User Management System is a web application that allows administrators to manage users and their financial activities efficiently.

The system provides a simple and responsive interface for:

- Creating and managing users
- Processing deposits
- Processing withdrawals
- Tracking account balances
- Monitoring financial activities
- Managing user information

This project was developed to demonstrate practical skills in front-end development, state management, data handling, and user interaction design.

---

## ✨ Features

### 👤 User Management
- Add new users
- Edit user information
- Delete existing users
- Search and manage user records

### 💵 Deposit Operations
- Deposit funds into user accounts
- Automatic balance updates
- Validation for entered amounts

### 💸 Withdrawal Operations
- Withdraw funds securely
- Prevent negative balances
- Real-time balance calculation

### 📊 Financial Tracking
- Account balance monitoring
- Transaction recording
- User activity management

### 🎨 Modern Interface
- Responsive design
- Clean dashboard layout
- User-friendly navigation
- Fast and interactive experience

## 🛠️ Installation

### Clone the repository

```bash
git clone https://github.com/Mohammad-arhami/User-Management-System-Deposits-and-Withdrawals.git
```

### Open the project

```bash
cd User-Management-System-Deposits-and-Withdrawals
```

Simply open:

```bash
index.html
```

or run it using a local server such as VS Code Live Server.
